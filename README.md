Mystery Madness

About

Mystery Madness is a text-based adventure game written in Python. The player must explore mysterious rooms, make choices, collect objects and solve puzzles to escape the maze.

How to Play

Follow the instructions displayed in the terminal.

Choose doors and objects to explore different paths.

Collect items that may help you progress.

Solve riddles and puzzles to reach the ending.

Enter your answers when prompted.

Features

Five levels to explore.

Multiple choices and different routes.

Input validation to handle invalid answers.

A secret code challenge.

A final randomised riddle.

How to Run

Run main.py using Python 3.

Technologies Used

Python
